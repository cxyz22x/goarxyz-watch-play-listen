# VidRock Stream Resolver

TypeScript **stream resolver** for [vidrock.net](https://vidrock.net). Resolve a **TMDB** movie or TV id to decrypted upstream **HLS** (`.m3u8`) / MP4 URLs, play them with **hls.js**, and export **direct** links for **VLC** and **MPV**.

Node.js 20+ · pure TypeScript (ESM) · `tsx` · curl upstream · AES-256-GCM decrypt

## Overview

A watch page is not the stream. Vidrock’s client fetches encrypted JSON, decrypts source URLs, then hits CDNs that expect the right Origin and Referer. This repo replays that path as a local **stream resolver**: catalog fetch → decrypt → open one mirror at a time → **hls.js** playback or external-player export, with an **HLS proxy** / relay when the browser cannot talk to the CDN directly.

## Features

- **TMDB resolve** — movie by id; TV by id, season, and episode
- **Sequential mirrors** — open servers in API order; first success plays; playback failure continues to the next idle server
- **Server badges** — every API entry with a real URL (null URLs skipped, same as the site)
- **Browser playback** — **hls.js** UI with per-server resolve and playback timers
- **External players** — copy upstream URL plus VLC / MPV commands with Origin and Referer where required
- **HLS relay** — playlist rewrite and segment relay for proxied mirrors; PNG unwrap for Nova-style segments
- **NDJSON API** — progressive `/api/resolve` for the UI or your own client

## Quick Start

```bash
npm install
npm start
```

Opens [http://localhost:3000/](http://localhost:3000/) after building `web/` → `dist/` and starting `tsx src/server.ts`.

1. Choose **Movie** or **TV**.
2. Enter a TMDB id (plus season and episode for TV).
3. Click **Resolve**.
4. Play in the browser or copy Direct / Browser / VLC / MPV.

| Script | Action |
| --- | --- |
| `npm start` | Build UI and run the server |
| `npm run build:web` | Compile UI to `dist/` only |

## Architecture

```mermaid
flowchart LR
  tmdb[TMDB id] --> api[vidrock API]
  api --> decrypt[AES-256-GCM]
  decrypt --> ndjson[NDJSON servers]
  ndjson --> open[Open one server]
  open --> hls[hls.js player]
  open --> export[VLC / MPV]
  hls --> relay[HLS relay]
  relay --> cdn[CDN]
```

| Stage | Responsibility |
| --- | --- |
| Input | Movie or TV query params |
| Catalog | curl to vidrock API with site Origin / Referer |
| Decrypt | AES-256-GCM source URLs |
| Open | One server at a time; Astra quality JSON → MP4 when needed |
| Play / export | Proxied URL for browser when required; direct URL for VLC / MPV |

## Resolve Flow

### Pipeline

| Step | Module | Behavior |
| --- | --- | --- |
| Parse input | `src/resolve/input.ts` | `movie` + id, or `tv` + id + season + episode |
| Fetch catalog | `src/vidrock/api.ts` | curl; short in-memory sources cache |
| Decrypt sources | `src/vidrock/crypto.ts` | Skip entries with `url: null` |
| Open mirror | `src/resolve/run.ts` | Sequential; optional `server=` for a single name |
| UI | `web/` | Badges, timers, player, exports |

### Crypto

Matches the published client path (not brute-forced):

1. base64url ciphertext  
2. IV (12 bytes) + ciphertext + auth tag (16 bytes)  
3. AES-256-GCM with the client bundle key  

No live key scraping.

### NDJSON Events

`GET /api/resolve` streams `application/x-ndjson`:

| Event | Payload |
| --- | --- |
| `meta` | Title label |
| `servers` | Names and formats (hls / mp4) |
| `server` | `loading` → `ok` or `fail` for the active mirror |

Pass `server=Name` to open only that mirror (badge click).

## Servers

Profiles in `src/servers/`. Names are API keys: Nova, Atlas, Luna, Orion, Astra. Only decrypted URLs are listed.

| Server | Typical format | Browser | VLC / MPV |
| --- | --- | --- | --- |
| Nova | HLS | HLS relay; PNG-wrapped segments stripped | Upstream URL |
| Atlas | HLS | Relay when listed | Per profile |
| Luna | HLS | Relay play URL; also direct-playable | Direct with Origin + Referer |
| Orion | HLS | Relay play URL; also direct-playable | Direct with Origin + Referer |
| Astra | MP4 | Direct after quality normalize | Direct |

Which mirrors appear depends on the title (upstream catalog), not on missing code.

## HLS Relay and Player

### Why the Relay Exists

**VLC** and **MPV** can set Referer / Origin on a **direct** m3u8. **hls.js** in the page cannot, and cross-origin playlists hit CORS. `/api/hls` is the local **HLS proxy**:

- Upstream fetch with the mirror’s profile headers  
- Rewrite playlist lines and `URI="…"` through `/api/hls?url=…`  
- Strip PNG wrappers on Nova-style segments (`src/relay/png.ts`)  

Only `needsProxy: true` hosts are accepted.

### Player Behavior

- Loads proxied or direct media via **hls.js**  
- Changing server clears player and export fields until that server is open  
- Resolve and playback times are per selected server  

## HTTP API

### `GET /api/resolve`

Stream resolver. Response: `application/x-ndjson`.

| Query | Required | Description |
| --- | --- | --- |
| `type` | yes | `movie` or `tv` |
| `id` | yes | TMDB id |
| `season` | TV | Season number |
| `episode` | TV | Episode number |
| `server` | no | Open only this server name |

### `GET /api/hls`

HLS proxy for manifests and segments.

| Query | Required | Description |
| --- | --- | --- |
| `url` | yes | Absolute upstream URL |

Returns rewritten m3u8 or segment bytes with CORS. Unknown or non-proxied hosts are rejected.

## Configuration

| Variable | Default | Role |
| --- | --- | --- |
| `PORT` | `3000` | Listen port |
| `VIDROCK_ORIGIN` | `https://vidrock.net` | API and Referer / Origin base |
| `USER_AGENT` | Chrome desktop UA | Upstream User-Agent |
| `SOURCES_CACHE_TTL_MS` | `60000` | Decrypted sources cache TTL |

## Project Layout

```
src/
  server.ts       HTTP entry
  env.ts          configuration
  wire/           curl transport
  vidrock/        API + AES-GCM
  resolve/        input + NDJSON stream
  servers/        Nova Atlas Luna Orion Astra
  relay/          HLS rewrite, play URL, PNG strip
  http/           router + static files
web/              UI source → dist/
dist/             built UI (gitignored)
```

| Piece | Detail |
| --- | --- |
| Runtime | Node.js ≥ 20, ESM, `tsx` |
| Language | TypeScript strict (`src/`, `web/`) |
| Browser HLS | hls.js at `/vendor/hls.mjs` |
| Upstream | curl (not Node `fetch`) |

Keep study dumps under `tmp/`, not in `src/` or `web/`.

## Extending Mirrors

1. Add a profile in `src/servers/` (`name`, `hosts`, `needsProxy`, `directPlayable`, `headers`, optional `normalizeUrl`).
2. Register it in `src/servers/index.ts`.
3. Leave relay policy in `src/relay/hls.ts` (unknown hosts stay rejected).
